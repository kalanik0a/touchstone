Touchstone

Hardware-bound privilege consent for AI coding agents. No AI agent gets root without a human physically present, reviewing the code, and touching hardware.

View on GitHub Documentation

The Problem

AI coding agents are gaining system access at an unprecedented rate. 88% of organizations deploying AI agents have experienced security incidents. The industry is building policy engines and OAuth scopes — but nobody built the physical consent layer at the OS level.

"Identity Is the Agentic AI Problem Nobody Has Solved Yet" — Resilient Cyber, 2026
"AI Agents Are Becoming Authorization Bypass Paths" — The Hacker News, 2026

The Solution

Touchstone fills the gap between "is this agent allowed?" and "did a human verify and authorize this specific action with a hardware trust anchor?"

Enterprise Policy (OPA, IAM, RBAC) Agent Identity (OAuth, SPIFFE, x509) ► Touchstone ◄ Hardware-bound auth (FIDO2/YubiKey) Visual code transparency (three-pane UI) PAM integration (OS-level, not custom) Agent-agnostic (Claude Code, Codex, Gemini, any agent) Operating System (PAM, sudo, SSH, TTY)

Three-Pane Consent UI

When an AI agent requests a privileged command, Touchstone opens a resizable terminal window with three panes:

Execution

Live command output. Password prompts and YubiKey touch happen here. The command runs only after you authenticate.

Code Review

The literal source code being executed — scripts, Makefile targets, or binary resolution. Scrollable, searchable, line-numbered. Displayed in less.

Inspector

Interactive bash shell with helpers: inspect, deps, perms, show_env. Investigate what a command does before you authorize it.

Tools

ts-sudo

Elevated commands with consent. Output captured and returned to the AI agent.

ts-ssh

Remote access with consent review. Supports cross-host PAM + FIDO2 auth chains.

ts-scp / ts-sftp

Secure file transfer with consent review. Output captured.

ts-run

Interactive command runner. For Makefiles, installers, anything with prompts. User interacts live.

Quick Start

# Install (any Linux)
git clone https://github.com/kalanik0a/touchstone
cd touchstone
sudo make install

# Verify
make check
ts-sudo whoami    # → three-pane window → authenticate → "root"
# NixOS (flake)
inputs.touchstone.url = "github:kalanik0a/touchstone";
modules = [ touchstone.nixosModules.default ];

Proven

Tested through the hardest auth chain possible:

# Double-hop reverse SSH with PAM + FIDO2
# Local → SSH → Prod → reverse SSH → Local → sudo + YubiKey → root

ts-run ssh -t user@prod "ssh -t localuser@local 'sudo whoami'"
# → root

Hardware-bound PAM auth survived a double-hop reverse tunnel. The YubiKey demanded physical touch at every privilege boundary.
